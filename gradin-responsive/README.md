# Gradin Responsive Landing Page

A responsive Vue 3 + Vite landing page concept for Gradin Digital Agency.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

- Responsive navigation for mobile and desktop.
- Semantic sections and accessible navigation controls.
- Fluid typography, CSS Grid/Flexbox, and reduced-motion support.
- Images are loaded from Unsplash; Google Fonts are used for typography.
- The design is a best-effort concept based on Gradin's public website and service information because the linked Whimsical design brief could not be opened in this environment.
